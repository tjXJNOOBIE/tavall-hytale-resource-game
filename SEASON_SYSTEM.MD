# How Seasons Work

Seasons will not be a "Season 1, Season 2, etc" system. Instead our seasons will go by the real seasons in real life.
* Example: "Spring 2026 Season/2026 Spring Season"
* If we need multiple seasons within this timeframe, we can do "Summer 2026 Season 2."
* This should combat the "Season 54" trope and should make calling back to seasons easier.
  * Instead of "Remember season 3?" while in season 23. Instead, players can just say, "Remember 2026 Spring Season?"
* This should also let content drops remain predictable and give us enough time in between seasons for big changes.
